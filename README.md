# agid-mcp releases

Release builds of the Atlas agent connector, for the agent setup steps the Atlas desktop app shows.

- `agid-mcp` — the agent connector CLI and MCP server (pairing, Claude Code, Codex, Hermes).
- `agid-openclaw-mcp` — the AGiD identity plugin for OpenClaw.

Each release holds the npm tarballs and their SHA-256 checksums. The Atlas app pins each tarball's checksum and verifies it before installing, so always follow the steps the app shows.
